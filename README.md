# Akhil K — Personal Portfolio Website

A modern, high-performance, and fully responsive personal portfolio website for **Akhil K**, combining Python/Django web development and creative digital storytelling.

Built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS v4** with a custom dark theme harmonized with Akhil's amber/gold shirt color palette.

## 🌐 How to Publish Under Your Name (Free Deployment)

You can publish this portfolio for free in **under 2 minutes** under your own name (e.g., `akhil-k.vercel.app` or a custom domain like `akhilk.in` / `akhilk.com`):

### Option A: Deploy to Vercel (Recommended - Easiest & Fastest)

1. Push this folder to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/akhil-anandan/portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account (`akhil-anandan`).
3. Click **"Add New Project"** and select your `portfolio` repository.
4. Leave settings as default (Framework Preset: **Vite**, Root Directory: `./`).
5. Click **"Deploy"**!
6. Your portfolio will be live at `https://akhil-k.vercel.app` (or custom name of your choice).
7. *(Optional)* Add your custom domain under **Project Settings > Domains**.

---

### Option B: Deploy with Vercel CLI Directly from Terminal

```bash
npx vercel
```
Follow the 3 prompts to name your project `akhil-k` and it deploys immediately!
